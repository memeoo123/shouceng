## 证据边界

关卡表、地图规则、波次、建筑形状/数值/合成公式、单位属性、暴击/闪避/击退、战斗等级、通用 trait、装备 trait、精英/头领转换、商店权重/保底/扩地规则、`UnitRoute` 转向算法和图片均来自授权包证据。装备专属 trait 的启用资格依赖玩家局外装备槽位及持久等级；没有账号快照时不凭空给本地初始档启用，但可通过显式 trait ID 调用全部 111 条有原运行时映射的公式。ID 104 `AllBarracksSpeed` 在原版本中缺少配置，按原缺陷保留为不可执行行。名为 `gravityengine.mg.layats.min.js` 的包内文件已确认是分析 SDK，不是战斗寻路器。当前以本地重叠集合代替 Laya 原生刚体接触集合；散射/穿透的角度、次数与时序来自原代码，命中选择则以本地角度筛选和 42 像素前向走廊代替原生 `BoxCollider` 触发。因此原生物理接触的逐帧时序仍不宣称等同；录屏时刻的进程级 `Math.random` 内部状态同样不在包体中。
